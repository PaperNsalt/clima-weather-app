## 📌 Description  
**CLIMA** is a modern web-based application that provides users with real-time weather information and location-based insights. It allows users to search, view, and save locations while displaying accurate weather data in a visually appealing and interactive interface.

Designed with usability and responsiveness in mind, CLIMA ensures a smooth experience across devices while delivering essential climate information efficiently.

---

## 🚀 Features  
- 📍 Search and view weather by location  
- 💾 Save favorite locations  
- 🌡️ Real-time weather updates  
- 🗺️ Interactive map integration (Leaflet)  
- 🎨 Modern UI with smooth animations  
- 📱 Fully responsive design  
- ⚡ Fast and dynamic performance  

---

## 🛠️ Technologies Used  
- **React.js** – Frontend framework  
- **Tailwind CSS** – Styling  
- **Framer Motion** – Animations  
- **Leaflet.js** – Map integration  
- **JavaScript (ES6+)** – Core logic
